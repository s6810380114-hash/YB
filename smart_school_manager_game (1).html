Smart School Manager

ภารกิจพิชิตโรงเรียนอัจฉริยะ

สวมบทบาทเป็นผู้จัดการโรงเรียนอัจฉริยะ นำทักษะ อัลกอริทึม ผังงาน และการคิดเชิงเงื่อนไข มาใช้บริหารจัดการแก้ปัญหาในโรงเรียนที่มีทรัพยากรจำกัด!

สิ่งที่คุณจะได้เรียนรู้จากภารกิจนี้:
  • เข้าใจการวางลำดับขั้นตอน (Algorithm) ในชีวิตจริง
  • ฝึกอ่านและเขียนผังงาน (Flowchart) เบื้องต้น
  • ตัดสินใจโดยใช้เงื่อนไข (If-Else) และประเมินผลกระทบ

คุณบริหารจัดการโรงเรียนครบทั้ง 4 วันสำเร็จเรียบร้อยแล้ว!

คะแนนการเรียนรู้ (Learning Score)
0 / 100 คะแนน
1. อัลกอริทึมและการเรียงลำดับ: 0 / 25
2. การอ่านและวิเคราะห์ผังงาน: 0 / 25
3. เงื่อนไขและการแก้ปัญหา: 0 / 30
4. เหตุผลและการสะท้อนคิด: 0 / 20

วิธีการเล่นเกม

1

คุณมี 4 ภารกิจหลัก ในการบริหารจัดการโรงเรียนอัจฉริยะ แต่ละภารกิจจะพบปัญหาที่แตกต่างกัน

2

ก่อนตัดสินใจ คุณจะได้รับ มินิเกมกิจกรรมวิทยาการคำนวณ (เรียงลำดับ/ผังงาน/เงื่อนไข) เพื่อเก็บคะแนนการเรียนรู้เต็ม 100 คะแนน

3

เลือกทางเลือกบริหาร 3 ทางเลือกในแต่ละภารกิจ การตัดสินใจในจุดก่อนหน้าจะ ส่งผลต่อสถานการณ์ถัดไป (Branching System)

4

คอยดูแล งบประมาณ คอมพิวเตอร์ และเวลา ไม่ให้หมดลงก่อนกำหนด!
